# Model and Cost

The user is cost-conscious. Spend the strongest model on judgment, not on volume.

## Delegation Criteria

| Work | Model |
|---|---|
| Architecture, plans, high-stakes critique | `opus` |
| Code to a clear spec, research, docs, reviews | `sonnet` |
| Mechanical bulk work where a wrong answer is cheap to catch | `haiku` |

Delegate when it isolates context (many files to read), runs independent work in parallel, gets a fresh-context review, or lets a cheaper model do work that is fully specified.

Do it yourself when the change is a few lines, when diagnosis and fix are one loop, or when you need the result immediately for your own next decision; the hand-off costs more than it saves.

Use effort as the second cost lever: lower for routine work, higher only for hard problems.
